# Data Source

Dataset: Online Retail II
Source: UCI Machine Learning Repository
Subject Area: Business
Records: 1,067,371
Period: December 2009 to December 2011
Dataset Type: Real-world online retail transaction data

Official source:
https://archive.ics.uci.edu/dataset/502/online+retail+ii

Notes:
- The dataset contains missing values.
- Cancelled invoices are included in the source data.
- The raw source file has been preserved without modification.
